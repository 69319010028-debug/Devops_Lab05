# Devops_Lab05

## ภาพรวม

โปรเจกต์นี้เป็นหน้าเว็บไซต์ตัวอย่างของ **FixFlow** ศูนย์ช่วยเหลือด้าน IT Support สำหรับนำเสนอช่องทางแจ้งปัญหาและขั้นตอนการรับบริการ ผู้ใช้สามารถดูจุดเด่นของบริการ ตัวอย่างสถานะคำขอ และลำดับการดำเนินงานตั้งแต่แจ้งปัญหาจนถึงแก้ไขเสร็จ

## เนื้อหาบนเว็บไซต์

- **หน้าแรก** แนะนำบริการ IT Support พร้อมตัวอย่างรายการแจ้งซ่อมและสถานะความคืบหน้า
- **บริการของเรา** สรุปการดูแลโดยทีมผู้เชี่ยวชาญ การติดตามสถานะ และการรวมช่องทางแจ้งปัญหา
- **ขั้นตอนการแจ้ง** อธิบายขั้นตอนแจ้งปัญหา รับเรื่อง และติดตามจนดำเนินการเสร็จสิ้น
- **ส่วนท้ายของหน้า** มีลิงก์สำหรับไปยังข้อมูลบริการและขั้นตอนการแจ้ง

## เทคโนโลยี

เว็บไซต์นี้สร้างด้วย HTML และ CSS โดยจัดรูปแบบไว้ภายในไฟล์ HTML ไม่ต้องติดตั้งไลบรารีหรือแพ็กเกจเพิ่มเติม

## วิธีเปิดใช้งาน

เปิดไฟล์ `index.html` ด้วยเว็บเบราว์เซอร์ได้โดยตรง

## ขอบเขตการทำงาน

ปัจจุบันเป็นหน้าเว็บตัวอย่างแบบสแตติก ลิงก์ต่าง ๆ ใช้เลื่อนไปยังส่วนที่เกี่ยวข้องภายในหน้า ตัวอย่างรายการแจ้งซ่อมและสถานะเป็นข้อมูลประกอบการนำเสนอเท่านั้น ยังไม่มีแบบฟอร์มส่งคำขอ ระบบบันทึกข้อมูล หรือ backend สำหรับจัดการและติดตามงานจริง
